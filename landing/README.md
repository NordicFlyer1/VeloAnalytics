# VeloAnalytics Landing Page

This folder contains a standalone, high-performance landing page for **VeloAnalytics**. It is designed to be hosted on **GitHub Pages** as a lead-in to your project.

## Features
- **Design System:** Matches the VeloAnalytics app (Orange accent, Swiss/Modern typography).
- **Metric Glossary:** Clearly explains complex concepts like Critical Power, W' Balance, and HRV.
- **Standalone:** No dependencies on the main application code—just a single `index.html` using Tailwind CSS and Lucide icons.

## How to use on GitHub Pages
1. Push this folder to your repository.
2. In your GitHub Repository Settings, go to **Pages**.
3. Choose to deploy from a branch (e.g., `main`).
4. Select the `/landing` folder as the source (if using the "docs" folder method, you may need to move it to `/docs/`).

## Project Structure
- `index.html`: The main entry point. All styles and scripts are self-contained or loaded via CDN.
