# 🍎 VeloAnalytics macOS & Siri Build Guide

This is the complete, unified step-by-step guide for building the **VeloAnalytics** native macOS desktop app using **Tauri & Rust**, incorporating **Siri Voice, Type to Siri, and macOS Spotlight** integration (Option 2 - Native Apple App Intents).

---

## 🧠 Architecture Overview

VeloAnalytics connects with macOS and Siri using a fast, battery-efficient **3-step relay**:

1. **React Web Application:**  
   Computes your readiness, recovery, power metrics, sleep, and rolling 7-day and 28-day training blocks.
2. **Tauri / Rust Bridge (`sync_siri_snapshot`):**  
   Whenever readiness or rides are calculated, Tauri writes a formatted JSON snapshot to your Mac's Application Support folder:  
   `~/Library/Application Support/com.bruce.veloanalytics/siri_snapshot.json`
3. **Apple Siri / App Intents (`VeloAppIntents.swift`):**  
   When you ask Siri or use Spotlight, macOS directly inspects that local JSON file.  
   - **Ultra-fast (<50ms):** Siri responds immediately without needing to open the full app.
   - **Offline & Private:** All physiological and power data remains strictly on your Mac.
   - **Zero Energy Overhead:** Operates smoothly even when VeloAnalytics is closed.

To make this effortless, all 5 configuration files are provided in:

| Target Path on Your Mac | Source in Repository | Purpose |
| :--- | :--- | :--- |

| Xcode Project File | `native-macos/VeloAppIntents.swift` | Native Swift App Intents & Siri phrases |

## 🚀 Step-by-Step Instructions

### Step 1: Clone / Pull the Repository to Your Mac

In your terminal:
```bash
git pull origin main
```

### Step 2: Copy the Verified Tauri Files

Copy the verified configuration files into your local `src-tauri` directory:

```bash
# From your project root:
cp native-macos/src-tauri-templates/Cargo.toml src-tauri/Cargo.toml
cp native-macos/src-tauri-templates/default.json src-tauri/capabilities/default.json
cp native-macos/src-tauri-templates/lib.rs src-tauri/src/lib.rs
cp native-macos/src-tauri-templates/main.rs src-tauri/src/main.rs
cp native-macos/src-tauri-templates/tauri.conf.json src-tauri/tauri.conf.json
```

### Step 3: Test in Local Dev Mode

Start your dev server:
```bash
npx tauri dev
```

1. Load your activities or sample rides in the app.
2. Verify in your terminal that the snapshot was written:
   ```bash
   cat "$HOME/Library/Application Support/com.bruce.veloanalytics/siri_snapshot.json"
   ```
   You will see your live `readinessScore`, `stressBalance`, `latestRide`, and training block totals!

## 🎙️ Integrating Siri (Option 2: Native App Intents)

### Option 2A: Native Xcode Build
1. Open the macOS Xcode project generated by Tauri (or add the target):
   ```bash
   # Ensure Xcode command line tools are selected
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
2. In Xcode, drag `native-macos/VeloAppIntents.swift` into your Xcode project navigator (check *"Copy items if needed"*).
3. Under your Target's **Signing & Capabilities**, click `+ Capability` and add **App Intents**.
4. Build the app (`⌘ + R` or `npx tauri build`).

### Option 2B: Instant macOS Shortcuts Integration (No Xcode Needed)
If you prefer not to open Xcode, you can hook into Siri immediately using the built-in macOS Shortcuts app:
1. Open **Shortcuts.app** (`⌘ + Space` → `Shortcuts`).
2. Click **`+` (New Shortcut)** and name it **"Velo Readiness"**.
3. Add these 3 actions:
   - **Get File from Folder:**  
     Navigate to `Library/Application Support/com.bruce.veloanalytics/siri_snapshot.json` (uncheck "Show Document Picker").
   - **Get Dictionary Value:**  
     Set key to `readinessScore`.
   - **Speak Text:**  
     `"Your Velo Readiness is (Dictionary Value) out of 100."`
4. Say: *"Hey Siri, Velo Readiness"* or type `Velo Readiness` into Spotlight.

## 📦 Building the Final macOS App for Release

> **Important macOS Rule:** Always ensure your project folder path has **no spaces or parentheses** (e.g. `~/Documents/VeloAnalyticsBuild/VeloAnalytics`), which avoids macOS linker string-table offset errors.

To build the full release macOS `.app` and `.dmg` bundle with a single command:

```bash
npm run tauri:build
```

*(This automatically runs Vite build and passes `-j 1` to Cargo so all macros link smoothly on Apple Silicon).*

If your binary is already compiled and you just want to re-bundle the `.app` and `.dmg`:
```bash
npm run tauri:bundle
```

The standalone application will be located at:
`src-tauri/target/release/bundle/macos/VeloAnalytics.app`
and the installer `.dmg` at:
`src-tauri/target/release/bundle/dmg/VeloAnalytics_*.dmg`

To package it cleanly for friends without permission errors:
```bash
cd src-tauri/target/release/bundle/macos/
ditto -c -k --sequesterRsrc --keepParent VeloAnalytics.app VeloAnalytics.zip
```
